# Project Index

This directory contains project-specific records for approved Philip Butler Workspace projects.

Workspace-level records remain in `project-office/` and track cross-project status, workspace decisions, shared risks, and workspace operating questions. Project-level records live under each `projects/<project-slug>/` directory and track only that project's brief, status, backlog, decisions, risks, archive, and items awaiting Philip.
